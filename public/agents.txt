# Key gotchas (machines: pull /.well-known/megachad-protocol.json#knownGotchas for the canonical list)
Gotcha-1: MegaChadLP uses tokenA/tokenB — generic Uniswap V2 router heuristics will fail. Use /api/defi/amm/* helpers.
Gotcha-2: MegaChadLP.swap requires the caller to push tokens to the pair BEFORE calling swap. /api/defi/amm/swap-tx returns the multi-step plan.
Gotcha-3: 1+ MEGACHADNFT required for ALL staking-reward eligibility. Verify via /api/defi/nft first.
Gotcha-4: Jestermogger proposal IDs are 1-indexed. proposalCount() returns the highest valid ID.
Gotcha-5: Check /api/defi/safety before sending any write — if CircuitBreaker is tripped, writes revert.
